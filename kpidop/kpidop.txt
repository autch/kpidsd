kpidop.kpi
==========

DSD (Direct Stream Digital) 音源を DSD Audio over PCM Frames (DoP) 方式
で再生するための KbMedia Player プラグインです。対応する拡張子は dsf,
dff, wsd です。

KbMedia Player 3.17beta6 以降のプラグイン仕様に対応しています。


対応 DSD DAC
------------

DoP Version 1.0 以降をサポートする DSD DAC で動作します。本プラグインの
実装は Version 1.1 の仕様に従っています。

5.6MHz 以上のサンプルレートには PCM サンプルレートを上げる方法で対応しま
す。マーカ 0x06/0xf9 を使う方式には対応していません（デバイスを持ってい
ないので）。

DSD のサンプリング周波数は、44.1kHz 系 (2.8224MHz、5.6448MHz、…) と 48kHz
系 (3.072MHz、6.144MHz、…) のそれぞれ 64 倍から 1024 倍までを受け付けま
す。DoP の PCM サンプルレートは DSD のサンプリング周波数の 1/16 です。

3ch 以上のファイルには DAC と出力デバイスが対応している必要があります。
DoP は本体がステレオにまとめられないので、出力デバイスが 3ch 以上に対応
していなければ再生できません (「マルチチャンネル」を参照)。3ch 以上の DSD
は作者も試せる機器を持っていないので、確認していません。

以下の DAC で動作確認しています。

- Roland UA-M10 (DoP via ASIO/WASAPI)
- KORG DS-DAC-100m (native DSD via ASIO)
- Sony Walkman NW-A307 USB-DAC mode (native DSD via ASIO)


KbMedia Player の構成
---------------------

このプラグインが出力した DoP フレームをビットパーフェクトを守ったままデ
バイスまで伝える必要があります。プラグインは DoP のデータであることを本
体に伝え、本体は最終出力段までデータを加工しません。

本体からのプラグイン出力ビット数要求が 24bit のときは 24bit INT で、そ
れ以外のときは 32bit INT で出力します。

ASIO/WASAPI (排他モード) が必要です。waveOut や DirectSound で再生しよう
とすると本体がエラーにします。

ASIO で DSD ネイティブ再生に対応したデバイスでは、本体付属の kbasio.kpi
の設定で、このプラグインの DoP を DSD ネイティブに変換して出力できます。
詳しくは kbasio.kpi の説明書をご覧ください。


デバイス設定
------------

お使いのデバイスに合わせて、KbMedia Player の「デバイス設定」ダイアログ
で以下の項目について設定を行ってください。

・デバイスインタフェース：ASIO か WASAPI を選択。両方使えるデバイスもあ
るし、どちらかでないと使えないデバイスもあるらしい。

・DSD再生形式（kbasio.kpi）：DoP か DSD Native から、デバイスがサポート
するほうを選択します。WASAPI では DoP しか使えません。

・デバイスへの出力ビット数：32bit INT か 24bit INT をチェック、デバイス
によって動作する組み合わせは変わるようですので、試行錯誤する必要があるか
もしれません。

ASIO4ALL 経由では使えないようです。ASIO サポートのないデバイスでは
WASAPI をおすすめします。


サポートしない機能
------------------

以下の機能は PCM を前提としているため、KbMedia Player 本体が検知して自動
的にオフまたは無効になります。

・ボリューム→つねに 100% 固定
・エコー
・ピッチスケール・テンポチェンジ
・クロスフェード
・リプレイゲイン
・フェードアウト
・スペアナ

このプラグインで再生中のとき、「曲の長さ」の PCM パラメータは
  176400Hz（2.8224MHz のとき）または 352800Hz（5.6448MHz のとき）など
  24bit または 32bit（プラグインへの出力ビット数要求に対応）
  mono または stereo
のように表示されます。


対応ファイルフォーマット
------------------------

以下のファイルフォーマットとバージョンに対応します。

・ソニー DSF v1.01
・フィリップス DSDIFF v1.5
・1bit オーディオコンソーシアム WSD v1.1

DSDIFF フォーマットにおける DST (Direct Stream Transfer) コーデックには
対応していないため、SACD から吸い出した音源の再生はそのままではできませ
ん。

以下の方法で入手したファイルフォーマットで動作確認しています。

- KORG AudioGate v3.0.2, v4.0.2 で生成した DSF/DSDIFF/WSD ファイル
- https://www.2l.no/hires/ でダウンロードできる DSDIFF, DSF ファイル
- e-onkyo music で購入した DSF ファイル
- 1bit オーディオコンソーシアム公式サイトの WSD ファイル


マルチチャンネル
----------------

3ch 以上 (7.1ch まで) のファイルを再生できます。9ch 以上のファイルは開
きません。

チャンネルの配置は、ファイルの情報から本体に伝えます。

  DSF     Channel Type (mono、stereo、3 channels、quad、4 channels、
          5 channels、5.1 channels)
  DSDIFF  CHNL チャンクのチャンネル ID (SLFT/MLFT、SRGT/MRGT、C、LFE、
          LS、RS。LS/RS はサラウンドの後ろの左右として伝えます)
  WSD     Channel Assignment (Lf、Lf-middle、Cf、Rf-middle、Rf、LFE、
          Lr、Cr、Rr)

ファイルの中のチャンネルの並びが WAV と違うとき (WSD の 5.1ch など) は、
WAV の並びに並べ替えて本体に渡します。配置が分からないとき (DSDIFF の
C000〜C999 や、WSD の Lr-middle/Rr-middle など) は、ファイルの並びのまま
渡し、本体はチャンネル数で決まる標準の配置で鳴らします。

DoP の 3ch 以上は、KbMedia Player 本体がステレオにまとめられません。
出力デバイスと DAC が 3ch 以上の DSD に対応していなければ再生できません。
ステレオで聞くときは kpid2p.kpi で PCM に変換してください。


対応 OS
-------

Windows 10 以降。Visual Studio 2026 の VC++ ランタイム (VC++ 再頒布可能パ
ッケージ) が必要です。KbMedia Player 本体付属のプラグインと同じです。


シークについて
--------------

シークはサンプル単位で正確に行います。

DoP のマーカーはシークをまたいでも 0x05 と 0xfa が交互に続くようにして
います。


タグ情報について
----------------

DSF の ID3v2 タグは、KbMedia Player 本体が解析します。そのためフレーム
名などの解釈は本体の実装に準じます。

DSDIFF に非公式の ID3 チャンク (FRM8 直下の "ID3 " チャンク) があれば、
その中の ID3v2 タグを DSF と同じく本体が解析します。このとき、次の DIIN
と COMT チャンクは使いません。

ID3 チャンクがなければ、Edited Master Information (DIIN) チャンクにある
DITI と DIAR チャンクが、それぞれタイトルとアーティストに対応します。
COMT チャンクがあれば、その中の最初の General Comment がコメントとして
使われます。General Comment がなければ最初のコメントを使います。
DSDIFF の仕様に文字コードの規定がないので、UTF-8 として正しければ UTF-8
として、そうでなければ Shift_JIS として解釈します。

WSD では、タイトル、アーティスト、アルバム、作曲者、ジャンル、コメント、
日時に対応します。WSD v1.1 の仕様には文字コードの規定がないので、
Shift_JIS として解釈します。

KORG AudioGate は、DSDIFF と WSD のタグに漢字などが含まれるとタグ情報自
体を記録しません。このため、DSDIFF の ID3 チャンクと、漢字などを含む
DSDIFF と WSD のタグは、テスト用に合成したファイルでしか確認していませ
ん。
