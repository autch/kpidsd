kpid2p.kpi
==========

DSD (Direct Stream Digital) 音源を PCM に変換して再生するための KbMedia
Player プラグインです。対応する拡張子は dsf, dff, wsd です。

KbMedia Player 2.80beta29 以降のプラグイン仕様に対応しています。

このプラグインは DSD ファイルフォーマットの実装を kpidop.kpi と共有して
います。このため、ファイルフォーマットやタグ形式サポートの状況は
kpidop.kpi と共通です。


DSD -> PCM 変換
---------------

1 段の FIR フィルタで DSD を間引いて、直接 PCM にします。出力のサンプリ
ング周波数は DSD のサンプリング周波数を 2 のべき乗 (8〜128) で割ったもの
で、別のリサンプラーは通しません。

たとえば 2.8MHz の DSD64 なら、以下のようになります。

DSD 1bit 2.8224MHz
-(FIR)-> PCM 64bit float 44.1/88.2/176.4/352.8kHz

・出力のサンプリング周波数は、本体から要求された周波数に一番近いものを、
  44.1kHz 以上 384kHz 以下から選びます。要求がなければ 88.2kHz です。
  44.1kHz 系の DSD からは 44.1kHz 系の、48kHz 系の DSD からは 48kHz 系の
  周波数になります。間引き率は 128 までなので、DSD256 では 88.2kHz
  (96kHz) 以上、DSD512 では 176.4kHz (192kHz) 以上になります。
・ASIO/WASAPI (排他モード) では、デバイスがその周波数で鳴らせないとエラー
  になることがあります。waveOut/DirectSound では、Windows が周波数を変換
  します。
・出力は浮動小数点 (本体から 32bit float を要求されたときは 32bit、それ
  以外は 64bit float) です。整数への変換やディザは本体に任せます。
・ゲインは 1 倍 (DSD のビットがすべて 1 のとき +1.0) です。
  同じ曲の PCM 版 (配信の flac など) は、制作時に +3dB や +6dB して変換さ
  れていることが多く、それより小さく聞こえます。上げると大きな曲で 0dBFS
  を超えるので、このプラグインではゲインを変えません。音量が足りないとき
  は、アンプなど再生機器の側で上げてください。v1.0.0 も同じゲインです。

フィルタはカイザー窓をかけた sinc で、起動時に作ります。

・通過域: 20kHz (44.1kHz 出力のとき) または 30kHz (88.2kHz 以上の出力の
  とき) まで。リップルは 0.0001dB 未満
・出力のナイキスト周波数 (44.1kHz 出力なら 22.05kHz) で -6dB
・阻止域: 出力の周波数から通過域の端を引いた周波数 (44.1kHz 出力なら
  24.1kHz、88.2kHz 出力なら 58.2kHz) より上を約 119dB 減衰
・ナイキスト周波数から阻止域の端までの成分は、通過域より上 (44.1kHz 出力
  なら 20kHz〜22.05kHz) に折り返します。通過域には入りません。
・直線位相です。PCM のサンプル k は DSD の k × (間引き率) サンプル目を中
  心に計算するので、出力の頭が遅れたり欠けたりしません。曲の前後は DSD の
  無音パターン (0x69) とみなします。


対応ファイルフォーマット
------------------------

以下のファイルフォーマットとバージョンに対応します。

・ソニー DSF v1.01
・フィリップス DSDIFF v1.5
・1bit オーディオコンソーシアム WSD v1.1

DSD のサンプリング周波数は、44.1kHz 系 (2.8224MHz、5.6448MHz、…) と 48kHz
系 (3.072MHz、6.144MHz、…) のそれぞれ 64 倍から 1024 倍までを受け付けま
す。

DSDIFF フォーマットにおける DST (Direct Stream Transfer) コーデックには
対応していないため、SACD から吸い出した音源の再生はできません。

以下の方法で入手したファイルフォーマットで動作確認しています。

- KORG AudioGate v3.0.2, v4.0.2 で生成した DSF/DSDIFF/WSD ファイル
- http://www.2l.no/hires/ でダウンロードできる DSDIFF, DSF ファイル
- e-onkyo music で購入した DSF ファイル
- 1bit オーディオコンソーシアム公式サイトの WSD ファイル


対応 OS
-------

Windows 10 以降。Visual Studio 2026 の VC++ ランタイム (VC++ 再頒布可能パ
ッケージ) が必要です。KbMedia Player 本体付属のプラグインと同じです。


シークについて
--------------

シークはサンプル単位で正確に行います。シークした位置から再生しても、先頭
から再生したときと同じ PCM になります。


タグ情報について
----------------

DSF の ID3v2 タグは、KbMedia Player 本体が解析します。そのためフレーム
名などの解釈は本体の実装に準じます。

DSDIFF に非公式の ID3 チャンク (FRM8 直下の "ID3 " チャンク) があれば、
その中の ID3v2 タグを DSF と同じく本体が解析します。このとき、次の DIIN
と COMT チャンクは使いません。

ID3 チャンクがなければ、Edited Master Information (DIIN) チャンクにある
DITI と DIAR チャンクが、それぞれタイトルとアーティストに対応します。
COMT チャンクがあれば、その中の最初のものがコメントとして使われます。
DSDIFF の仕様に文字コードの規定がないので、UTF-8 として正しければ UTF-8
として、そうでなければ Shift_JIS として解釈します。

WSD では、タイトル、アーティスト、アルバム、作曲者、ジャンル、コメント、
日時に対応します。WSD v1.1 の仕様には文字コードの規定がないので、
Shift_JIS として解釈します。

KORG AudioGate は、DSDIFF と WSD のタグに漢字などが含まれるとタグ情報自
体を記録しません。このため、DSDIFF の ID3 チャンクと、漢字などを含む
DSDIFF と WSD のタグは、テスト用に合成したファイルでしか確認していませ
ん。

ビットレートは kpidop.kpi と同じく、DSD のチャンネルあたりのビットレー
ト (DSD64 なら 2.822Mbps) を表示します。
